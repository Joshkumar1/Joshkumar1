### 👨‍💻 About Me

I am a **Software Engineer** and **Computer Science student** passionate about building impactful software combining modern web technologies with artificial intelligence. Instead of simply writing code, I focus on understanding problems from first principles, designing scalable systems, and engineering intuitive digital experiences that people genuinely enjoy using.

- 🚀 **Currently Building:** High-performance web applications, quantitative market intelligence terminals, and AI-driven educational platforms.
- 💡 **Engineering Philosophy:** *"Software engineering is an art form constrained by mathematics and performance. Decoupled state, strong type safety, and clean architecture lead to sustainable scale."*
- 🤖 **Applied AI Interests:** Computer vision, LLM orchestration, prompt architecture, and predictive analytics integrated directly into user workflows.
- 📐 **Foundational Focus:** Algorithmic thinking, Data Structures & Algorithms patterns, and microsecond-optimized client/server execution.
- 📍 **Location:** India 🇮🇳
- 💬 **Let's Talk About:** React 19, TypeScript, Node.js microservices, distributed system designs, or open-source collaboration.
